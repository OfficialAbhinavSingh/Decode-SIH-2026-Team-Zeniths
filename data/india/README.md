# National data — provenance

Every file here is either downloaded from an open source, or generated by a checked-in
script that documents its own sources in its module docstring. Run `make national` from
`backend/` (see `docs/PAN_INDIA.md`) to reproduce all of it from scratch.

| File | Built by | Source |
|---|---|---|
| `cities.csv` | `backend/pipelines/geo/registry.py` | GeoNames India dump (CC BY 4.0) |
| `zones_india.geojson` | `backend/pipelines/geo/build_zones.py` | Modelled from `cities.csv` — see `tessellate.py` for the method |
| `city_summary.csv` | `backend/pipelines/geo/build_zones.py` | Per-city rollup of the zone layer |
| `states.geojson` | one-off, this session | [datta07/INDIAN-SHAPEFILES](https://github.com/datta07/INDIAN-SHAPEFILES) `INDIA/INDIA_STATES.geojson`, simplified (Douglas-Peucker, tolerance 0.01°) and state names normalised to match `cities.csv`'s GeoNames spelling. Regenerate with `pipelines/geo/fetch_state_boundaries.py`. |
| `groundwater_cgwb2023.csv` | `backend/pipelines/water/load_groundwater.py` reads this; built one-off from the PDF | CGWB *National Compilation on Dynamic Ground Water Resources of India, 2023*, Annexure-I. Every row carries the extractable/extraction columns it was cross-checked against — run `python -m pipelines.water.load_groundwater --audit` to reproduce the check. |
| `rainfall.csv` | `backend/pipelines/water/rainfall.py` | Open-Meteo Historical Weather API (ERA5), fetched live |
| `billing_india.csv` | `backend/pipelines/billing/generate.py` | Synthetic, CPHEEO/AMRUT-benchmarked — same generator as the MVP, run against the national zone file |

`cities.csv`, `zones_india.geojson` and `city_summary.csv` are regenerated by the pipeline
and are not meant to be hand-edited. `groundwater_cgwb2023.csv` and `states.geojson` are
one-off transcriptions from source documents that do not expose a clean API; edit them
only by re-running the fetch, not by hand.
